# Keylogger Simples simulado com Python  

> Projeto educacional — desenvolvido em ambiente controlado para fins de estudo!  

## Aviso Importante  
Este código foi criado exclusivamente para aprendizado. A utilização de ferramentas de captura de teclado sem consentimento explícito é crime e pode acarretar penalidades.  

## Funcionalidades  
-  Captura teclas digitadas e salva em arquivo de log  
-  Reconhece teclas especiais: espaço, enter, backspace, shift, etc.  
-  Para a execução ao pressionar a tecla **ESC**  
-  Salva tudo na pasta do projeto  

## Tecnologias  
- **Python**  
- **pynput** — biblioteca para monitoramento de entrada do teclado  

## Como Executar  
```bash
# Instalar dependência  
pip install pynput  

# Executar  
python keylogger.py

# Parar
Pressionar a tecla 'ESC'

```
# Arquivos
keylogger.py - código principal  
log_teclas.txt - arquivo gerado com os registros do keylogger (criados automaticamente pelo código)
